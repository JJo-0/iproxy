# トラブルシューティング

[한국어](troubleshooting.md) · [English](troubleshooting.en.md) · [简体中文](troubleshooting.zh-CN.md) · **日本語** · [README](../README.ja.md)

| 症状 | 確認事項 |
| --- | --- |
| ダウンロードが 404 になる | 新しいリリースが未公開、またはファイル名が異なる可能性があります。Releases のファイル一覧を確認するか、README の手順でソースからビルドしてください。 |
| `Exec format error` | iSH には `iproxy-linux-386` が必要です。Mac/ARM 用の実行ファイルは使用できません。 |
| `Permission denied` | `chmod +x` または README の `install -m 755` を実行してください。 |
| 起動直後にポートのエラーが出る | 別の iProxy が動作していないか確認してください。ポートを変更する場合は、接続端末の設定も変更します。 |
| PAC URL を開けない | 共有接続、実際のゲートウェイ IP、iSH の動作状態、ローカルネットワークへのアクセス許可を確認してください。 |
| PAC のコードは表示されるが Web に接続できない | 手動 HTTP プロキシと curl でテストし、PAC 設定の問題と転送の問題を切り分けてください。iPhone 自体のモバイルデータ通信も確認します。 |
| ブラウザーだけ動作する | 他のアプリがシステムのプロキシ設定に対応しているか確認してください。UDP やすべてのアプリに対応する VPN ではありません。 |
| 画面ロック後に切断される | iSH を開き直し、プロセスが動作しているか確認してください。iOS によるアプリの一時停止には、確実な解決策はありません。`-l` は任意の実験機能です。 |
| `/dev/location` のエラー | iSH の環境やバージョンによっては位置情報デバイスが利用できません。`-l` なしで実行してください。 |
| プロキシ停止後にインターネットが使えない | OS の PAC／手動プロキシ設定と、シェルのプロキシ環境変数を解除してください。 |

`-v` のログにはリクエスト URL が含まれる場合があります。共有する前に個人情報を削除し、再現に必要な端末・OS・アプリのバージョンと起動オプションを記載してください。

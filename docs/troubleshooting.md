# 문제 해결

| 증상 | 확인할 사항 |
| --- | --- |
| 다운로드 404 | 새 릴리스가 아직 게시되지 않았거나 파일 이름이 다른 경우입니다. Releases의 파일 목록을 확인하거나 README의 소스 빌드를 사용하세요. |
| `Exec format error` | iSH에는 `iproxy-linux-386`이 필요합니다. Mac/ARM 실행 파일은 사용할 수 없습니다. |
| `Permission denied` | `chmod +x` 또는 README의 `install -m 755`를 적용하세요. |
| 실행 직후 포트 오류 | 다른 iProxy가 실행 중인지 확인합니다. 필요하면 포트를 변경하고 연결 기기의 설정도 함께 변경하세요. |
| PAC URL 접속 실패 | 핫스팟 연결, 실제 게이트웨이 IP, iSH 실행 상태, 로컬 네트워크 접근 권한을 확인하세요. |
| PAC 코드는 보이는데 웹 접속 실패 | 수동 HTTP와 curl로 테스트해 PAC 적용 문제와 프록시 전달 문제를 구분하세요. 아이폰 자체 셀룰러 연결도 확인합니다. |
| 브라우저만 동작 | 다른 앱이 시스템 프록시를 지원하는지 확인하세요. UDP와 모든 앱을 지원하는 VPN이 아닙니다. |
| 화면 잠금 후 끊김 | iSH를 다시 열고 실행 상태를 확인합니다. iOS의 앱 정지는 보장된 해결책이 없습니다. `-l`은 선택적 실험 기능입니다. |
| `/dev/location` 오류 | iSH 환경/버전에 따라 위치 장치가 없을 수 있습니다. `-l` 없이 실행하세요. |
| 프록시를 껐는데 인터넷 불가 | OS의 PAC/수동 프록시 및 셸 환경변수 설정을 해제하세요. |

`-v` 로그에는 요청 URL이 포함될 수 있습니다. 보고할 때 개인 정보를 제거하세요. 통신사별 결과는 요금제와 기기를 함께 기록하고, 프록시 연결 성공만으로 테더링 사용량 집계 방식이나 한도 우회를 판단하지 마세요.

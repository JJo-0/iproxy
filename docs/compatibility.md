## 검증 순서

1. 아이폰 자체에서 셀룰러 인터넷이 되는지 확인합니다.
2. 연결 기기의 프록시를 끄고 일반 핫스팟 연결 결과를 기록합니다.
3. iSH에서 `iproxy`를 실행하고 연결 기기에서 PAC URL에 접근합니다.
4. `curl --proxy http://<아이폰 IP>:8080 http://example.com`을 실행합니다.
5. 같은 HTTP 프록시로 `https://example.com`에 접근해 CONNECT를 확인합니다.
6. `curl --proxy socks5h://<아이폰 IP>:1080 https://example.com`으로 SOCKS5를 확인합니다.
7. OS의 PAC 설정 후 브라우저에서 HTTP/HTTPS를 확인합니다. 다른 프록시·VPN 설정을 중복 적용하지 않습니다.
8. 화면 잠금/앱 전환 후 1분·5분·15분에 다시 확인합니다. `-l` 사용 여부를 함께 적습니다.
9. 프록시 설정을 해제하고 정상 인터넷 연결로 복귀하는지 확인합니다.
